# TandemLink - Backend (Producto 3)

Backend puro desarrollado en **Node.js**, **ExpressJS**, **GraphQL** y **MongoDB** (utilizando el driver nativo oficial, sin Mongoose) para la plataforma educativa de intercambio de idiomas **TandemLink**.

Este repositorio corresponde al **Producto 3** de la asignatura y es completamente independiente de las entregas anteriores (Productos 1 y 2), centrándose exclusivamente en la lógica de servidor, API y persistencia NoSQL.
